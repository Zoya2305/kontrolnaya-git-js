# Книжная полка — контрольная работа

Проект объединяет задания по Git/GitHub, HTML5/JavaScript и работе с Google Таблицей через `fetch()`.

## Структура

* `index.html` — корректная структура HTML5, заголовок, текст, `<img alt>`, кнопка и таблица;
* `style.css` — адаптивное оформление;
* `script.js` — обработчик `click`, `console.log("Кнопка нажата")`, изменение текста, загрузка и разбор CSV, обработка ошибок;
* `config.js` — место для CSV-ссылки на опубликованную Google Таблицу;
* `assets/books.svg` — локальная картинка для тега `<img>`;
* `books.csv` — пример данных для импорта в Google Таблицу (5 строк);
* `AI\_PROMPT\_AND\_ANSWER.md` — запрос к ChatGPT и первоначальный ответ;
* `ai-report.md` — разбор ошибок, исправления и выводы;
* `setup-git.ps1` — создание локальных веток `main`, `dev` и трёх коммитов в `dev`.

## Подключение Google Таблицы

1. Откройте Google Таблицы и импортируйте `books.csv` (или впишите данные самостоятельно). Проверьте заголовки **Название, Автор, Год**.
2. Откройте **Файл → Поделиться → Опубликовать в интернете**. Выберите лист и формат **CSV**, нажмите **Опубликовать**.
3. Скопируйте ссылку вида `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`.
4. В `config.js` замените пустую строку на эту ссылку: `window.GOOGLE\_SHEET\_CSV\_URL = "https://.../pub?output=csv";`.
5. Перезагрузите сайт. Должна появиться надпись об успешной загрузке из Google Таблицы. Без подключения отображаются только демо-данные.

**Важно:** обычная ссылка с `/edit` не подходит. Не публикуйте личные или закрытые данные.

## Как запустить локально

Откройте `index.html` в браузере. Демо-данные и кнопка работают без сервера; после подключения Google CSV нужна сеть. Если браузер запрещает запрос из локального файла, откройте проект через локальный сервер (например, VS Code Live Server) или GitHub Pages.

## Git / GitHub / PR / Pages

Полная последовательность приведена в `INSTRUCTIONS.md`. **Сначала создаётся Pull Request из `dev` в `main`, затем он объединяется кнопкой Merge.** После слияния можно публиковать GitHub Pages из `main` / `(root)`.

## Проверка

* Кнопка меняет текст и пишет в консоль **Кнопка нажата**.
* Таблица отображает как минимум 3–5 строк.
* При ошибке сети выводится понятное сообщение, сайт остаётся доступным.
* Для зачёта загрузки из Google Таблицы необходима ваша настоящая ссылка CSV в `config.js`.

## Отчёт об использовании ИИ

См. `AI\_PROMPT\_AND\_ANSWER.md` и `ai-report.md`. В итоговом JS отмечены пояснения `// исправлено:`.
