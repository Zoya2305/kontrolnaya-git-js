# Инструкция для сдачи контрольной работы

Этот архив содержит готовую HTML5-страницу и JS. Для выполнения всех критериев **нужно привязать её к собственным GitHub и Google Таблице**. Эти действия нельзя подменять выдуманными ссылками.

## Шаг 1 — Google Таблица

1. Создайте новую Google Таблицу, импортируйте `books.csv` либо перепишите оттуда пять строк.
2. Убедитесь, что первые три заголовка — `Название`, `Автор`, `Год`.
3. Нажмите **Файл → Поделиться → Опубликовать в интернете** (или **File → Share → Publish to web**).
4. Выберите формат **CSV**, нужный лист, нажмите **Опубликовать**.
5. Скопируйте опубликованную ссылку и вставьте в `config.js` между кавычками.
6. Когда сайт опубликован, перезагрузите и проверьте сообщение «Данные успешно загружены из опубликованной Google Таблицы».

## Шаг 2 — локальный Git и три коммита в dev (Windows)

1. Установите Git for Windows, если он ещё не установлен.
2. Распакуйте архив в отдельную новую папку. Откройте там PowerShell.
3. Проверьте свою подпись коммитов командами `git config --global user.name` и `git config --global user.email`.
4. Если они пустые, выполните `git config --global user.name "Ваше имя"` и `git config --global user.email "email@example.com"`, указав **свои реальные** данные.
5. Запустите `powershell -ExecutionPolicy Bypass -File .\setup-git.ps1`.
6. Скрипт создаст `main`, `dev`, один базовый коммит в `main` и **три коммита в `dev`**. Активная ветка в конце — `dev`.

**Важно:** подключите Google CSV **до запуска скрипта**. Если вставляете ссылку позже, сделайте ещё один коммит в `dev`: `git add config.js` затем `git commit -m "Connect published Google Sheet"` и `git push`.

## Шаг 3 — публичный репозиторий и Pull Request

1. На GitHub создайте новый **публичный** репозиторий, например `kontrolnaya-git-js`. **Не добавляйте README, .gitignore или license через сайт**: они уже есть в проекте.
2. В PowerShell в папке проекта выполните (замените имя пользователя и репозитория):

   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/kontrolnaya-git-js.git
   git push -u origin main
   git push -u origin dev
   ```

3. На GitHub откройте **Pull requests → New pull request**. В `base` выберите `main`, в `compare` — `dev`.
4. Заголовок: **Добавлена страница с JavaScript и каталогом книг**.
5. Описание: **Создана HTML5-страница с изображением и кнопкой. Добавлена загрузка CSV из Google Таблицы через fetch(), обработка ошибок и отчёт по использованию ИИ. В ветке dev сделано три коммита.**
6. Нажмите **Create pull request**, сделайте скриншот PR (для сдачи), затем **Merge pull request → Confirm merge**.
7. **Не удаляйте ветку dev** до завершения проверки преподавателем. Сделайте скриншот истории коммитов или откройте вкладку Commits.

## Шаг 4 — публикация сайта

1. В репозитории GitHub откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите **main** и **/(root)**, нажмите **Save**.
4. После публикации GitHub покажет ссылку вида `https://ВАШ_ЛОГИН.github.io/kontrolnaya-git-js/`.
5. Откройте её и проверьте кнопку и список из Google Таблицы. В браузере нажмите F12 → Console и убедитесь, что после клика выводится `Кнопка нажата`.

## Шаг 5 — что отправить преподавателю

- Ссылку на публичный репозиторий GitHub.
- Скриншот трёх коммитов ветки `dev` и Pull Request (в том числе можно прикрепить по отдельности).
- Ссылку на сайт GitHub Pages.
- Ссылку на опубликованную Google Таблицу.
- При необходимости тот же ZIP-архив с файлами `index.html`, `script.js`, `README.md`, `ai-report.md`.

**Нельзя считать работу завершённой до публикации:** в исходном архиве Google CSV не подключён, а GitHub-репозиторий и PR ещё не существуют.
