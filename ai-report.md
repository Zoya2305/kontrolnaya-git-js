# Отчёт об использовании ИИ

Для создания JavaScript-части проекта был использован ChatGPT. ИИ получил запрос написать код, который загружает CSV-файл опубликованной Google Таблицы с колонками «Название», «Автор», «Год» и выводит книги на веб-страницу. Полный промпт и исходный пример ответа сохранены в `AI_PROMPT_AND_ANSWER.md`. Первоначальный пример показал основной принцип загрузки данных через `fetch()`, но не был готов к надёжному использованию. При проверке были обнаружены проблемы: отсутствовала проверка `response.ok` и обработка сетевых ошибок, CSV неверно разбирался при наличии запятых в кавычках, а строки вставлялись через `innerHTML`. В итоговом `script.js` эти участки переработаны: добавлены `try/catch`, проверка HTTP-статуса, обработчик CSV с кавычками и безопасное заполнение элементов через `textContent`. Комментарии `// исправлено:` в коде объясняют внесённые изменения. При отсутствии ссылки или ошибке загрузки сайт показывает явно обозначенные демонстрационные данные, а не пустую таблицу. Работа помогла понять, как связаны `fetch()`, CSV, события `click`, DOM и публикация сайта на GitHub Pages.

**Что проверить перед сдачей лично:** вставить свою опубликованную CSV-ссылку в `config.js`, убедиться, что внизу таблицы написано «Данные успешно загружены из опубликованной Google Таблицы», нажать кнопку и увидеть сообщение в консоли «Кнопка нажата»; также сделать скриншот веток/коммитов и Pull Request на GitHub.
