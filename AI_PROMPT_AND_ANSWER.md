# Промпт и первоначальный ответ ИИ

## Использованный ИИ-инструмент

ChatGPT (OpenAI).

## Промпт

> Напиши JavaScript для учебной HTML-страницы с таблицей книг. Данные находятся в опубликованной Google Таблице в формате CSV со столбцами «Название», «Автор», «Год». Нужно загрузить данные через fetch(), прочитать CSV и вывести список книг. Код должен быть простым и понятным начинающему.

## Первоначальный вариант, сгенерированный ИИ

```javascript
const csvUrl = "ССЫЛКА_НА_CSV";

fetch(csvUrl)
  .then((response) => response.text())
  .then((csv) => {
    const rows = csv.trim().split("\n").slice(1);
    document.querySelector("#books-list").innerHTML = rows
      .map((row) => `<li>${row.split(",").join(" — ")}</li>`)
      .join("");
  });
```

## Итоги проверки

Это **черновой ответ**, а не окончательный код. В нём не проверялся статус HTTP-ответа, не обрабатывались ошибки сети, CSV разбивался по запятым даже внутри кавычек, а `innerHTML` не подходил для вывода недоверенных значений из публичной таблицы. Кроме того, код искал `#books-list`, тогда как в итоговой странице использован `<tbody id="books-body">`.

Исправленная версия находится в `script.js`; комментарии `// исправлено:` указывают, что именно было доработано. В `ai-report.md` записаны выводы.
